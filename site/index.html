LOCAL APP · NOT A STATIC HOST FEATURE

Open the working console

The browser console talks to the FastAPI service and its local PostgreSQL database. A static GitHub Pages deployment contains the API reference and measured results, but it does not host the API.

To run the app, open a terminal in the project and execute:

uv sync --python 3.12 --all-groups
make demo

Then open http://localhost:8000/console/. This local demo creates sample accounts and transfers in your PostgreSQL volume; it does not make real payments.
